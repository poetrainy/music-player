# テスト仕様書

対象：Music Player（Next.js App Router / YouTube 連携音楽プレイヤー）
関連ドキュメント：[機能仕様書](./機能仕様書.md)

各表の列は共通で以下の意味を持つ。

- **手順**：ログイン後の状態を起点として、その項目の状態に至るまでの操作を番号付きですべて記載する（未ログイン状態を扱う一部の認証テストを除く）
- **期待結果**：正しい挙動として期待される結果
